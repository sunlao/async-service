Welcome to your new dbt project!

### Using the starter project

Try running the following commands:

- `docker exec -ti aserv-dbt sh -c "cd /src/xform && dbt debug"`
- `docker exec -ti aserv-dbt sh -c "cd /src/xform && dbt run --select tag:natal"`
- `docker exec -ti aserv-dbt sh -c "cd /src/xform && dbt test"`
